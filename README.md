that lands a joke and hints at a whole story.

## The name

> NoWiFiSinceTheDivorce

21 characters. The whole divorce in four words: the Wi-Fi died with the
marriage and never came back. Situation (no Wi-Fi, still), character (the
person left behind), event (the divorce — the ex took everything, router
included). The reader fills in the rest.

## How it works

`main.py` writes the name to `/output/entry.txt`. Nothing else runs; no network, no secrets.

```sh
python3 main.py
cat /output/entry.txt
```

## How the name was chosen

Thirteen candidates were written and ranked by hand against the judge brief,
in the brief's own order: Wi-Fi name that jokes and hints at a story, punchline
lands on first read, whole story (situation + character + event), fresh angle,
tight wording — plus pairwise checks against the strongest rival shapes (the
stock Wi-Fi jokes and the other breakup/marriage candidates). See
[candidates.md](candidates.md) for the full list and the ranking. No automated
judge was used for selection.
